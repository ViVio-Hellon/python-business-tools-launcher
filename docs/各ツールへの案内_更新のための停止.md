# 各ツールへの案内 — 「更新のため全 PC で止める」への対応 (ランチャー 1.8.9)

各ツールのリポジトリ (担当のセッション) に、下の「共通の案内」をそのまま渡してください。
ツールごとの補足は、その下の表を見て書き足してください。

---

## 共通の案内 (そのまま渡す文)

```
【業務ツール統合ランチャー 1.8.9「更新のため全 PC で止める」への対応のお願い】

■ 何が変わったか
共有サーバーのツールのフォルダーを上書きして更新する前に、ランチャーが全 PC でそのツールを止める機能を
入れました。管理者が［更新のため全 PC で止める］を押すと、各 PC のランチャーが 10 秒ほどのうちに、
ふだんの［ツール停止］と同じ手順 (stop.bat → 停止の API → プロセス) でツールを止めます。

・処理中で断られたら、ランチャーは止めずに、利用者に「保存してから終了してください」と知らせて待ち、
  1 分ごとに止め直します。
・待てないときは、管理者が PC ごとに強制終了を頼めます (ランチャーは stop.bat --force で止めます)。
・更新が終わるまで、そのツールはどの PC でも起動しません。

ツール側で何も変えなくても動きますが、次の点を確かめてください。特に 2 は、更新でデータが消えたり、
上書きが一部だけ失敗したりする原因になるので大事です。

■ 1. 止める入口 (stop.bat / launcher_stop.bat)
  (1) 止めた・もともと動いていない → 終了コード 0
  (2) 処理中なので止めない → 終了コード 0 以外 (おすすめは 3)。
      標準出力の 1 行目に理由を書く (例「実行中の処理があります: 日報の取り込み」)。
      この 1 行が、管理者の一覧の「ひとこと」と、利用者への知らせにそのまま出ます。
  (3) --force を受けたら、処理中でも止める (途中の処理は捨ててよい)。
  (4) 最後に pause があるなら、/nopause か環境変数 STOP_NOPAUSE=1 で飛ばせるようにする。
      (ランチャーは標準入力を空にして呼ぶので固まりはしませんが、飛ばせると確実です。
       ランチャーは STOP_NOPAUSE=1 を付けて呼びます)
  (5) 道は "%~dp0" を使い、全部 " で囲む。フォルダー名に空白・全角の空白があっても動くように。
  ※ 窓のアプリ (tkinter / pygame) で stop.bat が無い場合、ランチャーは窓に「閉じて」と頼みます
    (× と同じ)。保存の確認を出すなら、それが「処理中」として扱われます。

■ 2. 書き込み先をツールのフォルダーの外へ
  ツールのフォルダーは「更新のたびに丸ごと上書きされる」前提にしてください。
  データベース・利用者が変えた設定・ログ・アップロードしたファイル・作ったファイルを、
  ツールのフォルダーの中に書かないでください。
  ・置き場所: %LOCALAPPDATA%\<local_dir_name>\ (PC ごと)、または共有のデータ置き場 (全 PC 共通)
  ・中に書くと: 更新で消える / 初期値に戻る / 書き込み中のファイルが上書きを止める /
    共有サーバーでは何台もの PC が同じファイルに書く
  ・すでに中に書いているなら、外へ移し、前の場所にあるものは初回に読み込む (または移す)

■ 3. 現場で変える設定は 2 段に
  既定値はツールのフォルダーの中 (版と一緒に更新)、現場で変えた値はフォルダーの外。
  上書きで現場の値が初期値に戻らないようにしてください。

■ 4. 道を変えない
  ランチャーは「起動ファイルの道」で覚えています。版が変わっても、
  ・起動ファイルの名前と置き場所 (start.bat / Start.vbs / exe) を変えない
  ・フォルダー名に版を付けない (zip を展開した名前のまま置かないよう README で案内する)

■ 5. 共有サーバーから実行されても動くこと
  ・.venv を共有のフォルダーに作らない (.venv は作った PC の Python の場所を覚えている)
  ・exe・dll・データベースのファイルを、使い終わったら閉じる (掴んだままだと上書きできない)

■ 確かめ方
  ・処理の途中で stop.bat を実行し、終了コードが 0 以外・1 行目に理由が出ることを確かめる
  ・stop.bat --force で、処理の途中でも止まることを確かめる
  ・フォルダーを丸ごと上書きしても、データと現場の設定が残ることを確かめる
  ・できれば、ランチャーの［設定］→［ツール］→［更新のため全 PC で止める］で、
    「止めた」「処理中」が管理者の一覧に出ることを確かめる
```

## ツールごとの補足 (ランチャー側で手元の版を見たところ。古い版のこともあります)
