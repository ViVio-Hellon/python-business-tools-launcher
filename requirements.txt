# 業務ツール統合ランチャー — 追加パッケージ
#
# **ありません。** このランチャーは Python の標準ライブラリだけで動きます。
#
#     tkinter     … ランチャーバーと設定画面
#     sqlite3     … ツール設定(start.bat のパスなど)の保存
#     subprocess  … 各ツールの start.bat の実行
#     urllib      … 起動確認 (GET /api/health)
#     logging     … 起動・停止・エラーの記録
#
# ライン端末には追加ライブラリを入れられないため、この方針は変えません。
# 機能を足すときも標準ライブラリの範囲で収めてください。
#
# tkinter だけは Python 本体に含まれないことがあります(Windowsの公式
# インストーラでは既定で入りますが、外して入れることもできます)。
# `start_debug.bat --check` が入っているかどうかを確かめます。
#
# 各業務ツール側は Flask / waitress を使いますが、それは
# **それぞれのリポジトリの requirements.txt** の話で、ここには要りません。
